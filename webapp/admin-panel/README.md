# FeliCa Gate System - 管理画面

Next.js + TypeScript + Tailwind CSSで構築された管理画面アプリケーションです。

## 機能

### 管理者機能
- **ダッシュボード**: システム全体の統計情報を表示
- **ユーザー管理**: ユーザー一覧の閲覧、残高の確認・手動変更
- **入退場履歴管理**: trips（入場/出場記録）の一覧・絞り込み・キャンセル
- **カード管理**: 登録されたFeliCaカード・QRカードの一覧表示

### 一般ユーザー機能
現在は管理者機能のみ実装されています。今後、認証機能を追加し、一般ユーザーが自分の利用履歴と残高のみ閲覧できるようにする予定です。

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. サーバーの起動を確認

管理画面を使用する前に、バックエンドサーバーが起動していることを確認してください。

```bash
# serverディレクトリで
cd ../../server
python run.py
```

サーバーは `http://localhost:8000` で起動します。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアクセスします。

## 本番ビルド

```bash
npm run build
npm start
```

## 主要な画面

### ダッシュボード (/)
- 総ユーザー数
- 登録カード数
- 総利用回数
- 入場中の数

### ユーザー管理 (/users)
- ユーザー一覧の表示
- 残高の手動変更
- ユーザー詳細へのリンク

### 入退場履歴 (/trips)
- 入退場履歴の一覧表示
- ステータスでの絞り込み（入場中/完了/キャンセル）
- 誤った記録のキャンセル

### カード管理 (/cards)
- 登録されたカードの一覧表示
- カードタイプ（FeliCa/QR）の表示
- 関連ユーザーへのリンク

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Hooks (useState, useEffect)

## API連携

管理画面は以下のAPIエンドポイントを使用します：

- `GET /users` - ユーザー一覧取得
- `GET /users/{user_id}` - ユーザー詳細取得
- `PATCH /users/{user_id}/balance` - 残高更新
- `GET /trips` - 入退場履歴一覧取得
- `PATCH /trips/{trip_id}/cancel` - 履歴キャンセル
- `GET /cards` - カード一覧取得
